## サービス概要

対面の勉強会やMTGのアイスブレイク用に、七夕の短冊をオンラインで書いて飾れるWebアプリです。
ログイン画面はなく、ハンドルネームを入れて6桁のルームキーで「ルーム」に入るだけで参加できます。
書いた短冊は縦書きのカードとして共有ボードに並び、ハートでいいねを送るとカードが光ります。

![](./figures/app.png)

ルームを作った人は管理者として、QRコードでルームを共有したり、
短冊の公開・削除や投稿上限の変更をしたりできます。

![](./figures/app2.png)

## 開発の思い

七夕の日に、所属している情報サークルのMTGがたまたまありました。
せっかくなので何かアイスブレイクをやりたいと午前中に思い立ち、
「オンラインで短冊を書いて、みんなで笹に飾れるアプリ」を作ってその日のうちに使うことにしました。

参考にしたのは、リモート環境で交流の機会が減っていることを課題に、社内で七夕企画をした[記事](https://note.com/sales_wsff/n/n8ded5427462c)です。
そちらはformrunでアンケートを取り、Canvaで手作業で合成する形でした。
どうせなら、実際にリアルタイムで動くWebアプリにしてしまおうと考えました。

当日の6時間で作り切ることを目標にしたため、最初は認証なし・無料枠のみのシンプルな構成で作りました。
MTGで実際に使ったあと、サークル外にも公開することになり、2026年10月に不正対策を強化したv2に作り直しています。

## 技術選定の理由

6時間という制約の中で最初に決めたのは、「やらないことを早めに決める」ことでした。
初版は認証なし・Firestoreのルールは全開放・上限はlocalStorageで数えるだけ、という「認証ナシで動く最小構成」に全部倒して、
笹に短冊を飾る体験そのものに実装時間を使いました。

### Next.js + TypeScript + Tailwind CSS
画面はトップ・参加者画面・管理者画面の3つだけにし、ルームキーをそのままURL（`/{roomId}`、`/{roomId}/admin`）にしています。

### Firebase（Firestore + 匿名認証）
短冊がリアルタイムに増えていく体験を、サーバーを書かずに実現するためにFirestoreの`onSnapshot`を使いました。
Firebaseのクライアントからだけ読み書きし、API Routeや`firebase-admin`は使っていません。
v2では匿名認証を入れて、ログイン画面を作らずに各ブラウザへ偽装できないIDを持たせています。

## こだわり

### 七夕らしい見た目
短冊のテキストは`writing-mode: vertical-rl`で縦書きにし、赤・黄・青の短冊を投稿時に選べるようにしました。
いいねが多い短冊ほど段階的に光るので、人気の願い事がひと目でわかります。

### なりすましを防ぐハンドルネーム
短冊を書くたびに名前を自由入力できると、同じルームで他の人と同じ名前を名乗れてしまいます。
そこで、ハンドルネームはルームに入るときに一度だけ入力必須にし、以降はルーム内で書き換えられないようにしました。
投稿ごとに選べるのは「名前を表示する/しない」だけで、表示しない場合は「ななしさん」名義になります。

### 無料枠で回すための「公開トグル」
管理者が「みんなに公開する」を押すまでは、参加者には自分の短冊だけを購読させています。
全員が全件を購読し続けるとFirestoreの読み取り回数が膨らむため、無料のSparkプランに収める工夫です。
公開した瞬間に、全員の画面へ他の人の短冊がリアルタイムで現れる演出にもなっています。

### その場で共有できる
管理者画面の「共有する」から、ルームキーを大きく表示し、参加用リンクのQRコードを出せます。
QRコードは外部APIを使わず、`qrcode.react`でブラウザ内で生成しています。

## 開発で直面したこと

### 投稿上限・いいね上限をすり抜けられる
初版では、1人5枚までの投稿上限や1枚3回までのいいね上限を、localStorageで数えているだけでした。
開発者ツールで値を書き換えれば突破でき、Firestoreのルールも全開放だったため、サークル外への公開前に作り直しました。

v2では匿名認証の`uid`を投稿者IDにし、投稿数・いいね数のカウンタを短冊の作成と同じトランザクションで+1して、
Firestoreのセキュリティルールでその値を検証しています。
さらに、1回のバッチ書き込みでカウンタを1つだけ増やして短冊を複数作る、という迂回を防ぐため、
短冊のドキュメントIDを`{uid}__{カウンタ値}`に固定しました。
ルールはFirestoreエミュレータ上でテストを書いて確認しています。
